# Gon Preset Animator

## 使い方（最小手順）
1. **Tools > Gon Preset Animator** を開く
2. Avatar を指定
3. Weapon Root を指定
4. Preset を選択
5. **Build/Apply** → Play で **Preview** トグル

## サンプルプリセット
初回は **Create Sample Presets** ボタンで4種類のプリセットを生成します。

## テスト手順
1. Avatar 지정
2. Weapon 지정
3. Preset 선택
4. Build/Apply
